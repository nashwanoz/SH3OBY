# سمارت لينك

مشروع Android Studio بلغة Kotlin وواجهة Jetpack Compose لتطبيق إدارة المبيعات والمخزون.

## فتح وتجربة المشروع

1. ارفع **محتويات هذا المجلد** إلى مستودع GitHub مستقل، بحيث يكون `settings.gradle.kts` في جذر المستودع.
2. افتح المستودع في Android Studio.
3. انتظر مزامنة Gradle.
4. شغّل التطبيق على محاكي أو جهاز Android بإصدار 8.0 أو أحدث.

النسخة الحالية تبدأ ببيانات فارغة، وتدعم إضافة الفواتير والعملاء والأصناف والحركات المالية من داخل التطبيق. تُحفظ البيانات محليًا على الجهاز باستخدام تخزين Android المحلي، لذلك لا تظهر سجلات وهمية عند التثبيت.

تم تحسين تجربة الاستخدام لتشمل:

- إصدار فاتورة نقدية أو آجلة من نموذج إدخال فعلي.
- إضافة العملاء والأصناف والحركات المالية.
- تحديث لوحة الملخص تلقائيًا بعد كل إضافة.
- حفظ البيانات واستعادتها بعد إغلاق التطبيق.
- معالجة مساحة المحتوى أسفل شريط العنوان وشريط التنقل.
- ثيم عربي RTL بألوان وتباين ومسافات محسّنة.

## البناء عبر GitHub

يوجد ملف GitHub Actions في `.github/workflows/android.yml`. عند push إلى `main` أو `master`:

- يتم بناء نسخة Debug.
- تظهر `app-debug.apk` في Artifacts داخل نتيجة التشغيل.

يمكن تشغيل البناء يدويًا من تبويب Actions عبر `Run workflow`.
