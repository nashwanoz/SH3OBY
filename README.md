# خمر نت — Khamr Net

نظام نقاط بيع ومخزون عربي يعمل دون اتصال، مبني بـ Kotlin وJetpack Compose وRoom. يدعم المدير والكاشير، المخزون الفرعي لكل مستخدم، الصندوق المستقل، المبيعات النقدية والآجلة، السندات، التسويات، مزامنة Firebase الاختيارية، والطباعة ومشاركة الفاتورة عبر WhatsApp.

## التشغيل

1. افتح مجلد `khamr-net-android` في Android Studio Ladybug أو أحدث.
2. شغّل التطبيق على جهاز Android 8.0 أو أحدث.
3. حساب المدير الافتراضي عند أول تشغيل: اسم المستخدم `1` وكلمة المرور `1`.
4. لتمكين المزامنة، ضع ملف Firebase الحقيقي باسم `app/google-services.json`. التطبيق يبقى يعمل محليًا إذا لم يوجد الملف.

## التجميع عبر GitHub Actions

يوجد ملف التجميع في:

`.github/workflows/android.yml`

بعد رفع مجلد المشروع إلى مستودع GitHub، شغّل workflow باسم **Build Khamr Net Android** من تبويب **Actions** أو ادفع تغييرًا إلى فرع `main` أو `master`. سيظهر ملف `khamr-net-debug-apk` في قسم **Artifacts** بعد اكتمال البناء.

المزامنة مع Firebase اختيارية. إذا أردت تفعيلها أثناء بناء GitHub، أنشئ Secret باسم `GOOGLE_SERVICES_JSON` وضع داخله محتوى ملف Firebase بصيغة JSON. بدون هذا الـ Secret سيستمر البناء والتطبيق بالعمل محليًا دون اتصال.

## ملاحظات مهمة

- يتم إنشاء رقم الفاتورة محليًا بصيغة `Device_ID-User_ID-Sequential_Number`.
- كل عمليات البيع والتحويل والسندات والتسويات تُحفظ محليًا أولًا بعلامة `posted = 0`.
- عامل WorkManager يرسل العمليات غير المنشورة إلى Firebase، ثم يضعها `posted = 1` بعد النجاح.
- يلزم منح صلاحية Bluetooth من إعدادات الجهاز للطباعة على الطابعات الحرارية.
