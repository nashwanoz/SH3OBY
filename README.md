# سمارت لينك

مشروع Android Studio بلغة Kotlin وواجهة Jetpack Compose لتطبيق إدارة المبيعات والمخزون.

## فتح وتجربة المشروع

1. ارفع **محتويات هذا المجلد** إلى مستودع GitHub مستقل، بحيث يكون `settings.gradle.kts` في جذر المستودع.
2. افتح المستودع في Android Studio.
3. انتظر مزامنة Gradle.
4. شغّل التطبيق على محاكي أو جهاز Android بإصدار 8.0 أو أحدث.

النسخة الحالية هي طبقة واجهات أولية قابلة للتجربة، وتستخدم بيانات عرض مؤقتة. قاعدة Room، الحسابات الحقيقية، المزامنة، والصلاحيات التفصيلية تُضاف في المرحلة التالية بعد اعتماد شكل الشاشات.

## البناء عبر GitHub

يوجد ملف GitHub Actions في `.github/workflows/android.yml`. عند push إلى `main` أو `master`:

- يتم بناء نسخة Debug.
- تظهر `app-debug.apk` في Artifacts داخل نتيجة التشغيل.

يمكن تشغيل البناء يدويًا من تبويب Actions عبر `Run workflow`.
