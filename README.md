# POS Scaffold

This repository branch contains an Android POS scaffold (Kotlin + Jetpack Compose + Room) prepared for your project.

Structure:
- app/: Android app module
- README and basic Gradle files

How to run:
1. Open the project in Android Studio
2. Make sure `app/google-services.json` exists (it is included in this branch)
3. Sync Gradle and run on a device

Note: Firestore/BACKUP sync code skeleton included; enable Firestore in Firebase Console as instructed in the app README.
